# Employee HR Analytics Dashboard - Excel

📌 Overview
Analyzed 80 employees data to track workforce, salary, performance and attrition. Built an interactive Excel dashboard for HR decision making.

📊 Dashboard Preview
![Dashboard](Dashboard_Screenshot.png)

🔍 Key KPIs
* Total Employees: 80
* Active Employees: 50
* Avg Monthly Salary: ₹62,225.38
* Avg Performance Rating: 3.78

📈 Visuals Used
* Employee By Department - Column Chart
* Average Monthly Salary - Bar Chart
* Employee Distribution By Region - Pie Chart
* Employment Status - Donut Chart
* Employee Job Role - Bar Chart
* Performance & Attendance by Department - Line Chart
* Slicers: Department, Employment Status, Education, Job Role, Region

🛠️ Tools Used
* Microsoft Excel - Pivot Tables, Slicers, Charts, Dashboard Formatting

💡 Insights
* Most employees are in Sales & Operations departments
* South and North regions have highest employee concentration
* Active employees are higher than On-Leave and Resigned
